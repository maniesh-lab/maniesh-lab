## 🔧 What I'm building

A lead-gen automation pipeline, one stage at a time — each stage is its own
shipped repo:

| Stage | Project | What it does |
|---|---|---|
| 1. Scrape | [leadhound](https://github.com/maniesh-lab/leadhound) | Scrapy scraper pulling real estate agent listings |
| 2. Route & score | [Switchyard](https://github.com/maniesh-lab/Switchyard) | n8n workflow: cleans, dedupes, scores, and lands leads in Airtable |
| 3. LLM reliability | [Steadfast](https://github.com/maniesh-lab/steadfast) | Retry/rate-limit/logging layer for the agentic scoring layer to come |
| Standalone | [ragdocs](https://github.com/maniesh-lab/ragdocs) | RAG chatbot — FastAPI + Chroma + Streamlit |
| Standalone | [Hearth](https://github.com/maniesh-lab/Hearth) | Discord bot — onboarding, moderation, server-specific FAQ |

Next: an agentic scoring layer on top of Switchyard's output.
